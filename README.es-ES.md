# Aplicación meteorológica :
**Este programa es una herramienta para consultar el clima de las ciudades y mostrar todos los países y ciudades del mundo.**
<br>
<br>
**Instrucciones :**
<br>
<br>
**Para instalar las bibliotecas requeridas para este programa, puede usar el comando pip. Ejecute los siguientes comandos en su terminal o línea de comandos:**
**Instale el cliente NTP para la comunicación con el servidor de tiempo : pip install ntplib**
**Instale requests para solicitudes HTTP : pip install requests**
**Instale pycountry para trabajar con códigos de país : pip install pycountry**
**Instale GeonamesCache para datos geográficos : pip install geonamescache**
